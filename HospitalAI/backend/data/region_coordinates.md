# 행정구역 대표 좌표 자료

`region_coordinates.json`은 [공공데이터포털의 기상청 단기예보 조회서비스](https://www.data.go.kr/data/15084084/openapi.do)에 첨부된 격자·위경도 자료에서 읍·면·동 행을 추출한 자료다. 출처: 기상청, 공공데이터포털. 제공처의 이용 조건과 제3자 권리를 확인한다.

- 기준 원본: 2026-09-30 행정구역 시트, 2026-10-31 확인한 첨부 ZIP.
- 첨부 ZIP SHA-256: `9dfd7dc2d422318154d3484fb00142afa3c5271fc14d079adf997043a14b86ba`.
- 3,565개 읍·면·동 행. JSON 항목은 `code`, `province`, `district`, `locality`, `latitude`, `longitude`를 가진다.
- 이 좌표는 기상청 자료의 지역 대표점이며 주민의 실제 위치나 정확한 행정구역 중심이라고 보장하지 않는다. 거리 역시 이 대표점 기준의 대략적인 직선거리다.
- 원본은 광주·전남을 `전남광주통합특별시`, 코드 접두 `12`로 제공한다. 검색에서 다른 이름을 지원하려면 지역별 별칭을 따로 관리하고, 모호한 지명은 상위 지역을 재확인한다.

프로젝트의 `backend` 폴더에서 다음 명령으로 공식 첨부 파일을 다시 내려받고 가져올 수 있다.

```powershell
uv run --script scripts/import_regions.py --download data/region_coordinates.json
```

제공처가 첨부 파일을 교체할 수 있으므로 갱신할 때 자료 기준일, 지역명, 코드와 좌표를 검토하고 이 문서의 기준 시점과 해시를 갱신한다. 주소·좌표 확인 없이 모호한 지역에 대한 병원을 확정하지 않는다.
