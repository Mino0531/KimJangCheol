# HospitalAI

전화 상담과 지자체·병원 대시보드를 연결하는 가상 데이터 시연 프로젝트입니다. 실행과 연동 방법은 [RUN_INTEGRATION.md](RUN_INTEGRATION.md)를 참고하세요. 실제 환자 진료나 개인정보 처리에 사용하지 않습니다.

전화 서버와 화면은 `backend/`, `frontend/`에, 통합 대시보드의 현재 소스와 화면 빌드는 `external/KimJangCheol/`에 있습니다. 비밀 설정, 실행 데이터베이스와 음성 녹음은 저장소에 포함하지 않습니다. 대시보드는 기존 DB가 없으면 포함된 가상 fixture로 새 DB를 초기화합니다. 대시보드의 원본 안내 문서에서 언급하는 공유 SQLite 사본은 이 저장소에 포함하지 않습니다.

공개 저장소에는 로컬 데이터베이스, 비밀 설정과 서버 운영 설정을 포함하지 않습니다.
