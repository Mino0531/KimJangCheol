# 서비스 진입 화면

전화 상담, 지자체 접수, 실제 병원 대시보드, 방문준비카드 레퍼런스의 네 경로를 한 화면에 표시한다. 레퍼런스는 예시 자료임을 링크 설명에 명시한다.

기존 HospitalAI의 녹색 #2d6d5b, 중립 배경 #f4f6f5, 흰 표면 #fff, 본문 #21322e, 보조 글자 #52665f, 경계 #dce5e0을 사용한다. 글꼴은 시스템 한글 서체이며 본문 15px, 화면 제목 26–34px, 콘텐츠 너비 960px을 유지한다. 링크는 행 전체가 클릭 대상이며 포커스 외곽선을 제공한다. 모바일은 한 열로 표시한다.
